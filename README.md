# pairwise-audio-resampler

48k 素材放进 44.1k 工程后整段音高慢半个半音，线性插值没做带限，高频出现镜像；分数延迟按块独立累加，块边界相位不连续，每 1024 样本咔一下；可变帧率时间戳换算用整数除法，长时间累积后整轨偏移；左右声道各自重采样，相位不一致导致人声偏右；重采样后时长漂移，视频轨和音频轨越走越不同步；sinc 窗长固定，低频段信噪比掉得厉害；抖动噪声在 24bit 链路里按 16bit 幅度加，底噪被抬高；实时切采样率没重建滤波器状态，切换瞬间爆音；重采样和变速共用一个比例，变速后音高被二次修正；缓冲欠载时插静音，网络抖动变成断续。media/audio_resampler.py 是核心，tests/test_audio_resampler.py 15个红。要修的是：插值加带限滤波；相位跨块携带；时间戳按有理数换算；多声道共享相位；输出时长按样本数校正；窗长按比例自适应；抖动按位深缩放；切换时重建状态并淡入；重采样与变速分离；欠载做拉伸补偿。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
